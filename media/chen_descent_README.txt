    Project Full Title: The Descent 
    Short Name: descent
    Completed Date: July 29th 2026
    Medium: HTML, CSS, and p5.js script
    Course Info: MAT 111WN - WEB NARRATIVES by XIAO S 
    Abstract: It is a mainly a HTML webpage that hosts a p5.js script that plays like a old style dungeon crawler. It draws dungeon walls and project them into 3D space despite everything being in 2D. It has music, dialogues, and a combat system but is mostly a short linear experience. It is meant to depict someone who has forgotten about themself due to some traumatic experience, but is trying to leave this "dungeon" to regain their humanity. It is a mostly abstract experience that requires you to piece everything together from the descriptions of the items you pick up and dialogues.
