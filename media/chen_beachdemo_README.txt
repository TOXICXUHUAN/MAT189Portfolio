
    Project Full Title: BeachDemo
    Short Name: beachdemo
    Completed Date: August 1st 2024
    Medium: Unreal Engine 5 Project
    Course Info: MAT 111FS - MAD SKILLS FS by PATERAKIS I N
    Abstract: This is a VR Unreal Projects which features an island environment with various art exhibits with descriptions on every artifact. It also features water physics and some objects that you can interact with like throwing them around and watch them float on the water. It is meant to be an art exhibition of all the artifacts our group made for the class. I am responsible for making the Unreal project so I don't have an artifact for myself. To experience the exhibition, a VR headset is required. The participant can walk around the island and also by teleporting around using the controller. There are still and moving artifacts with the description text for each of them floating in air. I also made some beachballs that physically roll around that you can throw and they also have floating physics.
