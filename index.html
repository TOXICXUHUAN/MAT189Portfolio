    Beach Demo

    Unreal Engine 5 | 2024 | independent | Dylan Chen

    This is a VR Unreal Projects which features an island environment with various art exhibits with descriptions on every artifact. It also features water physics and some objects that you can interact with like throwing them around and watch them float on the water. It is meant to be an art exhibition of all the artifacts our group made for the class. I am responsible for making the Unreal project so I don't have an artifact for myself. To experience the exhibition, a VR headset is required. The participant can walk around the island and also by teleporting around using the controller. There are still and moving artifacts with the description text for each of them floating in air. I also made some beachballs that physically roll around that you can throw and they also have floating physics.

    The Descent

    Javascript | 2026 | independent | Dylan Chen

    Play The Descent

    It is a mainly a HTML webpage that hosts a p5.js script that plays like a old style dungeon crawler. It draws dungeon walls and project them into 3D space despite everything being in 2D. It has music, dialogues, and a combat system but is mostly a short linear experience. It is meant to depict someone who has forgotten about themself due to some traumatic experience, but is trying to leave this "dungeon" to regain their humanity. It is a mostly abstract experience that requires you to piece everything together from the descriptions of the items you pick up and dialogues.

    Wood Lantern with 3D Printed Handle

    Plywood and 3D Printing | 2024 | independent | Dylan Chen

    This is a lantern made mostly out of plywood with laser cut patterns. The patterns are of a alternating sequence between a bird and some geometric shapes. The inside has a 3D printed candle/LED holder. I first designed the patterns in Fusion360 and then tested out various designs by using the actual laser cutter and seeing which one works best. Then I modeled the handle and the candle holder to fit the notches I made for the panels. Then I laser cut the panels and 3D printed the handle and assembled them.

    MuseBeats

    Python, klotho-cac package | 2026 | independent | Dylan Chen

    This is a Python program that composes and plays a sequence of notes using multiple instruments that are similar to the band Muse's style. It uses supercollider so it runs on a server which is why it is hard to record a lossless version of the program. The chord progression is inspired by early Muse period especially from Showbiz to Absolution. Some of my favorite singles from this period include Citizen Erased, Plug in Baby,Thoughts of a Dying Atheist, and Host.

    Randomly Generated Artwork Program

    Python, Turtle graphics module | 2024 | independent | Dylan Chen

    This is a Python program that I wrote using the Turtle graphics module. I was inspired by how spiders weave their webs and some avant-garde modern artworks. The program works by following some basic rules on how to crop a preset list of art pieces and placing them somewhat randomly on the canvas. Then the turtle will draw shapes on top of them following some simple and arbitrary rules that crates lines and shapes. The randomness is seeded so you can produce the same result if you have the same seed.

    Orbhit

    Unity, C# | 2024 | Group Project | Dylan Chen, Malachiii, Electrocute Salesman, DOEBOII

    Play Orbhit

    This is a Unity game that I developed along with my teammates during the The Very Serious Juniper Dev Game Jam. The theme for the jam was "Spin to Win". The game features a ball chained to the player that does more damage the faster it spins. The player collects exp after killing enemies and can level up to obtain upgrades that strengthen various aspects of the ball. The game is meant to be a fast paced action game that requires the player to be constantly moving and dodging. Mastering the movement can be very rewarding for the player.

    Timekeeper

    Unity, C# | 2024 | Group Project | Dylan Chen, Zura Nero, Electrocute Salesman

    Play Timekeeper

    This is a Unity game that I developed along with my teammates for GMTK Game Jam 2026. It is a 3D platformer speedrunning game with a unique twist on the mechanics. The player is on a timer that isn't displayed on screen normally. Only by pulling out the watch can the player check the time. There are objectives on the map that must be interacted within a certain time not before or after. However, pulling your watch out also speeds up the passage of time the longer you have it out.
