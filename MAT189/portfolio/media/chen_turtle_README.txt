    Project Full Title: Randomly Generated Artwork Program
    Short Name: turtle
    Completed Date: August 1st 2024
    Medium: Python, turtle module
    Course Info: MAT 110CF - MAD CONCEPTS by FLATLEY D J 
    Abstract: This is a Python program that I wrote using the Turtle graphics module. I was inspired by how spiders weave their webs and some avant-garde modern artworks. The program works by following some basic rules on how to crop a preset list of art pieces and placing them somewhat randomly on the canvas. Then the turtle will draw shapes on top of them following some simple and arbitrary rules that crates lines and shapes. The randomness is seeded so you can produce the same result if you have the same seed.
